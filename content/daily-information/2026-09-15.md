## 计算神经科学与 AI

### 1. 适应可能由六种跨基底计算原语组成

**The Computational Primitives of Adaptation（适应的计算原语）** 是 **arXiv 预印本，首发 2026-09-08，未同行评审**。来源：[arXiv:2609.11989](https://arxiv.org/abs/2609.11989)。

作者提出 Arouse（唤起）、Orient（定向）、Valence（价性）、Position（定位）、Boundary（边界）和 Attune（调谐）六类原语，并主张用它们重述注意、记忆和决策等行为，也可作为分析提示注入、奖励劫持和灾难性遗忘的人工系统框架。论文是 34 页的理论工作，列出可证伪预测，但没有新的动物记录、神经元数量或定量行为实验。

**为什么值得关注**：它提供了一个把神经计算与脑启发 AI 对齐的可讨论词汇，可用于将群体动力学指标映射到更具体的功能假设。**关键局限**：六原语的必要性、不可约性和跨物种普适性尚未被实验验证；不应把概念框架写成已证实机制。

### 2. pyAvalanches：神经雪崩时空传播的可复用 Python 流程

**pyAvalanches: A Python Package for Analyzing Spatiotemporal Propagation in Neuronal Avalanches（用于分析神经雪崩时空传播的 Python 软件包）** 是 **arXiv 预印本，首发 2026-09-10，未同行评审**。来源：[arXiv:2609.11530](https://arxiv.org/abs/2609.11530)。

软件从 EEG 等电生理记录检测雪崩，计算大小/持续时间分布，并以 ATM 描述传播路径，再导出网络神经科学指标；作者用公开静息态 EEG 做群体示例分析。其 scikit-learn 兼容、模块化设计有利于把实验室脚本变成可比较的流水线，但本次仅核验 arXiv 摘要，尚未核对 PyPI 当前版本、仓库提交和许可证。

**为什么值得关注**：ATM 与网络指标正好连接临界性、群体动力学和跨会话复现，可作为钙成像或电生理分析的候选基线。**关键局限**：雪崩定义、阈值和预处理对结果敏感；预印本中的临床 EEG 示例不能直接外推到小鼠皮层。

### 3. 蝗虫启发的生物合理脉冲网络做碰撞感知

**A Bio-Plausible Visual Neural Network for Locust-Inspired Collision Perception（蝗虫启发的生物合理视觉神经网络）** 是 **arXiv 预印本，首发 2026-09-09，未同行评审**。来源：[arXiv:2609.10183](https://arxiv.org/abs/2609.10183)。

模型模拟蝗虫复眼的空间各向同性采样，使用群体编码式投票和 leaky integrate-and-fire 神经元替代 sigmoid 激活；作者在合成刺激、实验室序列和真实驾驶场景上报告复杂视觉条件下的鲁棒性与计算效率提升。摘要未给出数据规模、统计显著性、能耗或与现代事件相机/脉冲基线的完整对照。

**为什么值得关注**：各向同性采样、群体投票和 LIF 是可移植到神经形态硬件的明确设计组件，适合做脑启发视觉消融。**关键局限**：目前只有预印本摘要级证据，且“生物合理”主要是结构类比，不等于已复现蝗虫 LGMD 的全部生理动力学。
