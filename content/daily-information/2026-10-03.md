### 1. 果蝇下降神经元的共享输入对应更邻近的突触布局

**Synaptic placement reflects shared input in Drosophila descending neurons｜果蝇下降神经元的突触位置反映共享输入**是 **arXiv 预印本，未同行评审**，v1 首次提交 **2026-09-30**，在 10 月 2 日的 q-bio.NC 新提交批次中上线。来源：[arXiv:2610.00690](https://arxiv.org/abs/2610.00690)。

研究比较 independently reconstructed 的 **MaleCNS 与 FlyWire** 果蝇脑连接组。在数千条单向下降神经元（DN）连接中，如果某个上游来源也连接到配对 DN，那么该来源在接收 DN 上的输入位置，沿神经突起测量时平均比其他非 DN 输入更接近配对 DN 的输入：两个数据集分别约近 **9.4 µm 与 8.0 µm**。固定来源输入位置并标准化参照集合大小后，这一顺序仍成立；在 BANC 与 MaleCNS 中，共享输入和形态空间重叠还提供互补的连接预测信息。

**为什么值得关注**：这把“三神经元拓扑关系”连接到单细胞内部的突触几何，提示连接组约束模型不能只保留邻接矩阵，还应考虑输入在树突上的相对位置。**关键局限**：这是重建连接组上的统计关系，不是钙成像、电生理或行为因果实验；跨数据集复现增强了稳健性，但不能单独证明邻近输入产生了特定非线性整合或运动功能。

本窗口未发现优先级更高、且尚未在最近晨报报道的小鼠在体认知/记录论文；因此没有用较弱的旧研究补位。

## 计算神经科学与 AI

### 2. MTS-SLDS 从切换状态中恢复神经群体的多时间尺度

**Inferring Multi-Timescale Neural Dynamics with Switching Linear Dynamical Systems｜用切换线性动力系统推断多时间尺度神经动力学**是 **arXiv 预印本，未同行评审**，v1 首次提交 **2026-10-01**。来源：[arXiv:2610.01786](https://arxiv.org/abs/2610.01786)。

MTS-SLDS 用多滞后矩初始化捕捉不同时间延迟上的结构，再以状态条件化的 Laplace-EM 减少不确定状态之间的动力学统计混合，最终从潜变量转移矩阵的特征值提取时间尺度。在 128 通道、10 维潜变量的合成切换 Poisson 数据中，MTS-SLDS 与标准 SLDS 的留出轨迹重建都达到 **R²=0.82**，但状态平衡准确率为 **0.95 对 0.54**，时间尺度误差为 **11% 对 44%**；在低计数条件下，其中位误差低 **1.7–3.3 倍**。

作者还分析了猕猴 **16 通道 V4** 注视任务记录，以及 Area 2 主动伸手/被动扰动记录。V4 中模型在留出试次上每试次对数似然提高 **52.4±6.9**，并得到约 **26.4、49.5、120.2 ms** 的三个可重复时间尺度。

**为什么值得关注**：它适合行为状态切换、跨脑区群体记录和稀疏脉冲数据，比把整个 session 压成单一自相关常数更贴近真实实验。**关键局限**：估计的是模型假设下的“有效时间尺度”，无法区分局部回路本征动力学与未观测的持续输入；近邻衰减率、短状态停留和记录长度不足都会降低可辨识性，目前也没有核验到配套实现仓库。

### 3. MEG-Mamba 用状态空间模型降低神经基础模型训练成本

**MEG-Mamba: A Scalable State-Space Foundation Model for Magnetoencephalography｜可扩展的 MEG 状态空间基础模型**是 **arXiv 预印本，未同行评审，CC BY 4.0**，v1 首次提交 **2026-09-30**。来源：[arXiv:2610.00746](https://arxiv.org/abs/2610.00746)；[官方仓库](https://github.com/OHBA-analysis/MEG-Mamba)。

模型在 Cam-CAN 的 **559 个训练 session、87 小时**静息态 MEG 上，以 100 个 Schaefer 分区、250 Hz 信号做自回归 token 预测，并保留 62 个未见受试者 session 测试。相对 Transformer 基线 MEG-GPT，作者报告预训练开销为 **22 对约 400 GPU 小时**，上下文为 **4 对 0.32 秒**；用 LoRA 只训练约 16.7 万个参数，还可从静息态预训练模型生成视觉、听觉和按键诱发响应。

**为什么值得关注**：复杂值状态空间更新与脑信号振荡结构天然契合，也让神经数据基础模型的规模化实验更便宜。**关键局限**：论文主要评估生成信号的时空与频谱保真度，尚未证明广泛下游任务或跨数据域优于专用模型；只报告单次训练种子。仓库公开代码、tokenizer 与权重，但本次未找到明确软件许可证，因此应称为“源代码和开放权重可访问”，不宜笼统称为开源。

### 4. 局部 motif 与全局 hub 对脉冲网络相干性各有贡献

**Stochastic Dynamics of Large-Scale Motif-Embedded Spiking Neuronal Networks｜嵌入 motif 的大规模脉冲神经网络随机动力学**是 **arXiv 预印本，未同行评审**，v1 首次提交 **2026-09-30**。来源：[arXiv:2610.00616](https://arxiv.org/abs/2610.00616)。

作者在 **1,000 个 Izhikevich 神经元**上比较 Erdős–Rényi、scale-free 及其 motif 嵌入版本，并用突触数匹配的无 motif 网络作对照。局部 motif 增强了噪声诱导相干性，但对刺激传输的提升较小；scale-free 网络整体相干性更高、传输更快，选择性破坏高连接度兴奋性 hub 的损害也强于随机删点或删边。

**为什么值得关注**：它把局部高阶连接模式与全局度分布放在同一控制框架中，适合连接组约束 SNN 的结构消融。**关键局限**：结果来自理想化随机网络和 Izhikevich 仿真，并非真实连接组或在体记录；刺激传输差异相对试次间波动较小，且未核验到代码发布。

### 5. 网络足够宽时，逐层局部自监督训练可逼近端到端反向传播

**Increasing Width Allows Greedy Layer-wise Training to Rival End-to-End Backpropagation in Self-Supervised Learning｜增加宽度使贪心逐层训练逼近端到端反向传播**是 **arXiv 预印本，未同行评审，CC BY 4.0**，v1 首次提交 **2026-09-30**。来源：[arXiv:2610.00753](https://arxiv.org/abs/2610.00753)。

研究系统改变卷积网络的宽度和深度，比较逐层局部优化与端到端自监督训练。随着网络变宽，反向传播的优势缩小；在较浅、极宽的条件下，局部训练甚至出现更好的下游表现，并伴随更有利的表征几何。

**为什么值得关注**：它为受限信用分配和更生物可行的局部学习提供了明确的架构条件，也提示脑启发学习规则需要与宽度、冗余和表征维度共同评估。**关键局限**：这是卷积网络上的机器学习结果，不是突触可塑性模型或生物神经记录；“不做端到端误差传播”也不自动等同于生物可行，摘要页未给出代码仓库。

### 6. 平衡脉冲网络被实现为低功耗伪随机数发生器

**Neuromorphic Pseudo-Random Number Generators with a Low Power Hardware Implementation｜带低功耗硬件实现的神经形态伪随机数发生器**是 **arXiv 预印本，未同行评审，CC BY-NC-ND 4.0**，v1 首次提交 **2026-09-30**。来源：[arXiv:2610.00719](https://arxiv.org/abs/2610.00719)。

作者把兴奋—抑制平衡的 LIF 脉冲网络量化并部署到 iCE40UP5K FPGA；摘要报告运行功耗 **3.24 mW**、吞吐率 **120 kbps**。在软件测试中，约一半的输入或权重配置通过全部 15 项 NIST SP 800-22 测试，另约 40% 通过 14 项；TestU01 SmallCrush 的 100 个结构配置也全部通过。

**为什么值得关注**：它把“平衡网络的高维混沌状态”变成了实测硬件功能，属于脑启发计算从动力学到电路的少见闭环。**关键局限**：统计测试通过不等于密码学安全，论文也没有给出安全证明或攻击分析；吞吐率远低于许多传统硬件 PRNG，且未核验到源代码或硬件设计发布。

## 开源工具与数据

### 7. suite2p-in-depth：双光子轴向运动估计与校正

**Correcting axial-motion artifacts in two-photon calcium imaging with suite2p-in-depth｜用 suite2p-in-depth 校正双光子钙成像轴向运动伪影**是 **bioRxiv 预印本，未同行评审，CC BY 4.0**，实际发布 **2026-09-30**（DOI 标识为 `10.64898/2026.09.25.754364`）。来源：[bioRxiv/DOI](https://doi.org/10.64898/2026.09.25.754364)；[官方仓库](https://github.com/Schroeder-Lab/suite2p-in-depth)；[Figshare 数据，CC BY 4.0](https://doi.org/10.6084/m9.figshare.33981469)。

工具提供两条互斥流程：较大且始终留在深度范围内的结构使用独立参考 z-stack 校正 ROI/neuropil 轨迹；轴突或 bouton 等可能离开单平面的结构使用密集多平面采集重建共同深度电影。在清醒小鼠中，z-stack 路线的深度估计 RMSE 低于 **1 µm**，多平面 z-registration 为 **0.69–1.03 µm**；校正对一部分 soma 的荧光影响明显，对轴突 bouton 更大。

**适用场景与门槛**：仓库为 **GPL-3.0-only**，固定依赖 Suite2p v1.1.0 的不可变 commit，支持 Python 3.12；Windows/Linux CPU 已列入支持矩阵，CUDA 需要匹配的 PyTorch 环境。它要求实验阶段额外采集密集参考 z-stack 或紧密多平面数据，不能事后凭单平面数据无条件补救；仓库页面尚未列出正式 GitHub Release，使用时应固定提交并保存 run manifest。

### 8. SAAD-EEG：开放的无指令双耳竞争注意数据

**A High-Density EEG Dataset for Stimulus-Driven Auditory Attention｜刺激驱动听觉注意的高密度 EEG 数据集**是 **arXiv 数据论文预印本，未同行评审**，v1 首次提交 **2026-10-01**。来源：[arXiv:2610.01303](https://arxiv.org/abs/2610.01303)；[Zenodo 10.5281/zenodo.20557225](https://doi.org/10.5281/zenodo.20557225)；[MIT 许可预处理仓库](https://github.com/yanruofan628/saad-preprocessing)。

资源包含 **23 名健康成人、每人 3 个 session、每 session 160 个 trial** 的 128 通道、250 Hz EEG；每个 trial 同时向左右耳呈现自然声音，参与者不预先接收注意目标，而是在刺激后报告更吸引注意的一侧。Zenodo 提供原始 MFF、预处理 epoch、480 对双耳刺激、反应时和主观评分，总量约 **24.2 GB**，数据为 **CC BY 4.0**、代码为 **MIT**。论文的 Bradley–Terry 刺激优先级模型把未见声音配对的留出 AUC 从 **0.577 提高到 0.718**。

**适用场景与门槛**：适合测试听觉注意解码、跨 trial 泛化、多模态证据融合和 EEG 基础模型；预处理后数组仍需约 16.3 GB 空间。样本只有 23 人，标签是主观报告的刺激驱动定向，而不是外部指定的注意真值；作为预印本数据描述符，仍需独立复现和跨设备验证。

## 今日最值得读/试

1. **先读 MTS-SLDS 的合成恢复实验与两套猕猴记录**：重点区分“轨迹预测好”与“时间尺度/状态识别正确”，并检查潜维数、状态数和观测模型敏感性。
2. **如果近期有清醒小鼠双光子数据，优先试 `suite2p-in-depth` 的 `validate` 与 `--dry-run`**：先根据采集方式在 z-stack 校正和多平面 z-registration 中二选一，再用工具的诊断图检查深度估计是否可信。
3. **连接组分析加入突触空间零模型**：在只保留拓扑的重连之外，比较共享输入在树突上的相对距离是否仍异常集中；这可直接借鉴果蝇 DN 论文的控制思路。
4. **把 SAAD 当作神经基础模型的小型外部泛化集**：固定 23 人的 subject-wise split，避免 trial 泄漏，并将刺激声学优先级与 EEG 增量贡献分开报告。
