## Pipeline (Old, based on ssid)

### Data Processing and Neuron Extraction Pipeline

To handle the large-scale 3D light-field data acquired by the RUSH3D system, we utilized the standard computational pipeline provided by the system developers **(Zhang et al., 2024)**. The processing workflow consists of the following key steps:

**Pixel Realignment and Preprocessing:** Raw sensor data were computationally realigned to synthesize high-resolution phase-space views. To facilitate efficient parallel computing and handle the centimeter-scale field of view (FOV), the data were partitioned into overlapping tiles.

**Multiscale Background Rejection (MBR):** To mitigate strong background fluorescence inherent in wide-field imaging of thick tissue, the Multiscale Background Rejection (MBR) algorithm was applied **(Zhang et al., 2021)**. Spatially nonuniform backgrounds were estimated from down-sampled phase-space views and subtracted from the raw measurements to enhance the signal-to-background ratio (SBR).

**Motion Correction and Seed Generation:** Following background rejection, rigid motion correction was performed on the phase-space data using the NoRMCorre algorithm **(Pnevmatikakis and Giovannucci, 2017)** to stabilize tissue movements. Initial neuron coordinates (seeds) were generated by computing a standard deviation projection of the motion-corrected video. This summary image was then reconstructed using Wave-optics Digital Adaptive Optics (wDAO) **(Wu et al., 2021)** to correct for system- and tissue-induced aberrations. Bright neurons within the aberration-corrected volume were identified via morphological segmentation to serve as initial spatial footprints ( $$A_{init}$$).

**Sparse Seeded Iteration Demixing (SSID):** For high-speed signal extraction, the Sparse Seeded Iteration Demixing (SSID) algorithm was employed **(Zhang et al., 2024)**. Instead of reconstructing every frame, SSID extracts neuronal signals directly in the light-field space using only a sparse subset of angular views (e.g., 13 out of 225 views) to reduce computational redundancy. The algorithm utilizes a constrained non-negative matrix factorization (NMF) approach, iteratively updating spatial footprints and temporal traces ( $$F

$$
) by minimizing the residual between the measured sparse light-field data and the projection of estimated neuronal components.

## Pipeline(New, DL enhanced)

### **High-Throughput Data Processing Pipeline**

To address the computational challenges imposed by the massive data throughput of the RUSH3D system, we established a high-performance, parallelized computational pipeline. This pipeline features a distributed architecture leveraging multi-GPU acceleration and TensorRT optimization to achieve millisecond-scale inference speeds. The processing workflow is divided into three distinct stages:

1. Preprocessing and Rigid Motion Correction

The raw scanning light-field data were computationally partitioned into a  $$5 \times 7$$grid of overlapping patches (blocks) to facilitate distributed parallel processing. For each patch, geometric optical distortion was corrected block-wise based on pre-calibrated parameters, followed by pixel realignment to synthesize high-resolution phase-space views.

To mitigate artifacts arising from tissue pulsation and respiration, we implemented a rigid motion correction module based on the **NoRMCorre** algorithm **(Pnevmatikakis and Giovannucci, 2017)**. Given that the relative optical alignment between angular views in light-field microscopy remains constant, we adopted an efficient correction strategy: rigid motion vectors were estimated solely from the central angular view (View 0) of the phase-space. These vectors were then globally applied to all simultaneous angular views within the same time point. This approach preserves phase-space consistency while significantly reducing computational overhead.

2. Deep-Learning-Based Real-time 3D Reconstruction

We employed a deep-learning framework, termed SERENet (Spatially Embedded Reconstruction Network), to rapidly reconstruct high-resolution 3D volumetric stacks from light-field data. The reconstruction module, accelerated via TensorRT, consists of two key components:

- **Implicit Aberration Correction (DL-PreDAO):** Prior to volumetric reconstruction, a grid-sampling-based deep learning module (DL-PreDAO) was utilized to implicitly model and correct complex optical aberrations induced by both the system and the biological specimen. This module predicts a deformation grid to spatially transform the input phase-space views, optimizing ray alignment before reconstruction.
- **Volumetric Reconstruction:** The aberration-corrected data were first projected into standard deviation (STD) maps to enhance the contrast of neuronal structures. The SERENet core network then directly mapped these STD projections to high-resolution 3D neuronal volumes.
- **Network Training:** The network was trained using a supervised learning approach with paired experimental data. We acquired ground-truth 3D volumes using two-photon microscopy and simultaneously captured light-field images of the same field of view for network optimization.

3. 3D Segmentation and Signal Extraction

Neuronal identification within the reconstructed volumes was performed using a 3D U-Net segmentation network. The network assigned a probability score to each voxel, semantically segmenting connected neuronal regions of interest (ROIs) from the background.

For high-throughput temporal signal extraction, the generated 3D segmentation masks were projected back onto the motion-corrected time-series volumes. We extracted the raw fluorescence signal
$$

F*{raw} $$ for each neuron and the signal from the surrounding neuropil $$F*{neuropil}$$. To correct for local background contamination, we applied the standard neuropil subtraction formula (Chen et al., 2013):

$$F_{corr} = F_{raw} - \alpha \cdot F_{neuropil}$$

where the subtraction coefficient $$\alpha

$$
was set to 0.24. Finally, extracted neurons from all 35 patches were stitched based on their spatial coordinates to generate a seamless, cortex-wide functional map.

where the subtraction coefficient  $$\alpha$$ was set to 0.24. Finally, extracted neurons from all 35 patches were stitched based on their spatial coordinates to generate a seamless, cortex-wide functional map.
