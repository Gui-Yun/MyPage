## Overview

This note keeps two versions of the RUSH3D fluorescence-processing workflow: the original SSID-based pipeline and the newer deep-learning-enhanced high-throughput pipeline. The emphasis is on how raw light-field measurements are converted into neuron masks and temporal fluorescence traces.

## Pipeline (Old, Based on SSID)

### Data Processing and Neuron Extraction Pipeline

To handle the large-scale 3D light-field data acquired by the RUSH3D system, we used the standard computational pipeline provided by the system developers **(Zhang et al., 2024)**. The workflow consists of the following key steps.

**Pixel Realignment and Preprocessing:** Raw sensor data were computationally realigned to synthesize high-resolution phase-space views. To facilitate efficient parallel computing and handle the centimeter-scale field of view (FOV), the data were partitioned into overlapping tiles.

**Multiscale Background Rejection (MBR):** To mitigate strong background fluorescence inherent in wide-field imaging of thick tissue, the Multiscale Background Rejection (MBR) algorithm was applied **(Zhang et al., 2021)**. Spatially nonuniform backgrounds were estimated from down-sampled phase-space views and subtracted from the raw measurements to enhance the signal-to-background ratio (SBR).

**Motion Correction and Seed Generation:** Following background rejection, rigid motion correction was performed on the phase-space data using the NoRMCorre algorithm **(Pnevmatikakis and Giovannucci, 2017)** to stabilize tissue movements. Initial neuron coordinates were generated by computing a standard deviation projection of the motion-corrected video. This summary image was then reconstructed using Wave-optics Digital Adaptive Optics (wDAO) **(Wu et al., 2021)** to correct for system- and tissue-induced aberrations. Bright neurons within the aberration-corrected volume were identified via morphological segmentation to serve as initial spatial footprints $A_{\mathrm{init}}$.

**Sparse Seeded Iteration Demixing (SSID):** For high-speed signal extraction, the Sparse Seeded Iteration Demixing (SSID) algorithm was employed **(Zhang et al., 2024)**. Instead of reconstructing every frame, SSID extracts neuronal signals directly in the light-field space using only a sparse subset of angular views, for example 13 out of 225 views, to reduce computational redundancy. The algorithm uses a constrained non-negative matrix factorization (NMF) procedure to iteratively update spatial footprints $A$ and temporal traces $F$:

$$
\min_{A,F \geq 0} \|Y - AF\|_F^2 + \lambda_A R_A(A) + \lambda_F R_F(F)
$$

Here, $Y$ denotes the measured sparse light-field data, $A$ denotes neuronal spatial footprints, and $F$ denotes temporal fluorescence traces.

## Pipeline (New, DL Enhanced)

### High-Throughput Data Processing Pipeline

To address the computational challenges imposed by the massive data throughput of the RUSH3D system, we established a high-performance, parallelized computational pipeline. This pipeline uses a distributed architecture with multi-GPU acceleration and TensorRT optimization to achieve millisecond-scale inference speeds. The processing workflow is divided into three stages.

### 1. Preprocessing and Rigid Motion Correction

The raw scanning light-field data were computationally partitioned into a $5 \times 7$ grid of overlapping patches. For each patch, geometric optical distortion was corrected block-wise based on pre-calibrated parameters, followed by pixel realignment to synthesize high-resolution phase-space views.

To mitigate artifacts arising from tissue pulsation and respiration, we implemented a rigid motion correction module based on **NoRMCorre** **(Pnevmatikakis and Giovannucci, 2017)**. Because the relative optical alignment between angular views in light-field microscopy remains constant, rigid motion vectors were estimated only from the central angular view (View 0) of the phase-space. These vectors were then globally applied to all simultaneous angular views within the same time point. This strategy preserves phase-space consistency while reducing computational cost.

### 2. Deep-Learning-Based Real-Time 3D Reconstruction

We employed SERENet (Spatially Embedded Reconstruction Network) to rapidly reconstruct high-resolution 3D volumetric stacks from light-field data. The reconstruction module, accelerated via TensorRT, consists of two components.

**Implicit Aberration Correction (DL-PreDAO):** Before volumetric reconstruction, a grid-sampling-based deep learning module was used to model and correct optical aberrations induced by both the system and the biological specimen. This module predicts a deformation grid to spatially transform the input phase-space views and optimize ray alignment before reconstruction.

**Volumetric Reconstruction:** The aberration-corrected data were first projected into standard deviation (STD) maps to enhance the contrast of neuronal structures. The SERENet core network then mapped these STD projections to high-resolution 3D neuronal volumes. The network was trained using paired experimental data: ground-truth 3D volumes acquired by two-photon microscopy and simultaneously captured light-field images from the same field of view.

### 3. 3D Segmentation and Signal Extraction

Neuronal identification within the reconstructed volumes was performed using a 3D U-Net segmentation network. The network assigned a probability score to each voxel, semantically segmenting connected neuronal regions of interest (ROIs) from the background.

For high-throughput temporal signal extraction, the generated 3D segmentation masks were projected back onto the motion-corrected time-series volumes. For each neuron, we extracted the raw fluorescence trace $F_{\mathrm{raw}}(t)$ and the surrounding neuropil trace $F_{\mathrm{neuropil}}(t)$. Local background contamination was corrected using:

$$
F_{\mathrm{corr}}(t) = F_{\mathrm{raw}}(t) - \alpha F_{\mathrm{neuropil}}(t)
$$

where the subtraction coefficient $\alpha$ was set to 0.24. Finally, neurons extracted from all 35 patches were stitched based on their spatial coordinates to generate a cortex-wide functional map.
